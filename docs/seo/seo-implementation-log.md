## Changes by area

### Technical SEO
- **`astro.config.mjs`**
  - `trailingSlash: 'always'`.
  - Sitemap `filter` drops `/404/`, `/blog/`, `/privacy/`, `/terms/` (all noindex).
  - Astro Fonts API config for Inter and Space Grotesk (Google provider,
    variable weight 400–700, latin, normal style).
- **All internal links** (55 hard-coded hrefs in 12 files, plus
  `product.url` in `src/data/products.ts`) now end in `/`.
- **`src/layouts/BaseLayout.astro`**
  - An interim inline `<head>` script redirected `http:` visitors to
    `https:`. It was removed once Cloudflare's "Always Use HTTPS" was on;
    Cloudflare now answers every HTTP request with a 301.
  - `noIndex` pages get `noindex, follow` (was `noindex, nofollow`) and no
    canonical. Indexable pages keep a self-referencing canonical.
  - New props: `seoTitle`, `ogType`, `pageType`, `breadcrumbs`,
    `structuredData`, and a `head` slot for page-specific tags.
  - Google Fonts `<link>`s replaced by `<Font … preload />`.
  - `<noscript>` style keeps `.reveal` content visible without JavaScript.
  - The scroll-reveal observer moved from the bundled module script to an
    inline script at the end of `<body>`, so first-viewport content appears
    when the page is parsed.
- **`src/data/site.ts`** (new): site URL, `@id`s, person facts, `pageTitle()`
  (appends "— Arun Alex George" when the result is ≤ 65 characters).

### Structured data
One `@graph` per indexable page (171 pages):
- `WebSite` (`/#website`) and `Person` (`/#person`) on every page. Person facts
  match the about page: job title, employer, Kochi/Kerala/IN, `sameAs`
  LinkedIn, GitHub, Medium and the Odoo App Store author listing.
- `WebPage` / `ProfilePage` (about) / `ContactPage` / `CollectionPage`
  (services, products, portfolio).
- `BreadcrumbList` on every page below home, matching the visible "All
  Services" / "All Products" back links.
- `Service` on the nine service pages, `provider` → Person.
- `SoftwareApplication` on 153 product pages (was a separate block): now in the
  graph, `author` → Person, plus `license`, `applicationSubCategory`,
  `softwareRequirements`. Price and currency come from the store sync.
- **Deliberately not added:** `AggregateRating`/`Review` (no real reviews on
  the site), `LocalBusiness` (no public business premises), `FAQPage` (Google
  shows FAQ rich results only for authoritative government and health sites).
  As a result, **product pages are not eligible for Google's software rich
  result**, which requires ratings. Do not add fake ratings to change that.

## Maintenance notes

- New internal links must end in `/` (`/contact/`, not `/contact`). The Astro
  dev server enforces this with `trailingSlash: 'always'`.
- After a product sync adds a new industry product or Community-gap app, add a
  curated title to `src/data/product-seo.ts` if the default is weak.
- When the first blog article is published, remove `noIndex` from
  `src/pages/blog.astro` and `/blog/` from `NOINDEX_PATHS` in
  `astro.config.mjs`.
- Regenerate the social image after changing the avatar or headline:
  `npm run generate:social`.

## Rollback

- **Before merge:** delete the branch (`git branch -D seo/audit-and-implementation`).
  `master` is untouched.
- **After merge, everything:** `git revert <merge-commit>` and push.
- **One piece:** each area is self-contained. For example, to undo only the
  portfolio image move, revert the `src/pages/portfolio.astro` and
  `src/components/home/Portfolio.astro` hunks and `git mv` the PNGs back to
  `public/portfolio/`.
- **HTTPS:** handled by Cloudflare (SSL/TLS mode Full, Always Use HTTPS,
  `www` redirect rule). Undo there, not in code.
